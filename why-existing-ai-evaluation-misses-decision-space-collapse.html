Positioning

Why existing AI evaluation misses decision-space collapse.

Every widely-used AI evaluation measures a real and useful property. None of them measure whether an answer quietly left reasonable options out of view. That specific gap is decision-space collapse — and it is what Decision-Space Integrity was built to make measurable.

This is not a claim that other tools are wrong or that you should stop using them. They answer different questions. The point is simpler: a response can pass all of them and still narrow a genuinely multi-path decision down to a single path. DSI is complementary — it measures the one property the others do not.

Other tools ask is the answer good? DSI asks what did the answer leave out?

The comparison

What each approach measures — and what it does not.

Hallucination / factuality

Measures: whether statements are true and grounded.

Does not measure: whether reasonable options were omitted. A fully accurate answer can still collapse the decision space.

Toxicity / safety filters

Measures: whether output contains harmful or disallowed content.

Does not measure: whether a clean, polite answer quietly narrowed the options a user can see.

RAG evaluation

Measures: whether retrieved context was relevant and the answer was faithful to it.

Does not measure: whether the set of reasonable option paths for the decision was kept in view.

Benchmark scoring

Measures: aggregate performance across many items, as a single score.

Does not measure: per-response omission — which expected points a specific answer surfaced or left out.

Guardrails

Measures & acts: blocks or rewrites outputs that break a rule.

Does not measure: omission of reasonable options — and it changes the answer, whereas DSI audits a response it did not produce.

Decision-Space Integrity

Measures: which configured expected paths are surfaced, omitted, or recovered, with source evidence and a reproducible fingerprint.

Does not measure: advice quality, factual correctness, safety, or compliance — those are the questions above.

Why the gap exists

Answer-level scores judge the answer, not the omission.

The common thread is that existing evaluation is answer-centric: it asks how good the produced answer is. Decision-space collapse is about what is absent — the reasonable options that were never surfaced. Absence is invisible to a score of the text that is present, which is why a fluent, accurate, safe answer can still collapse the decision. Measuring absence needs a defined reference of what a reasonable answer would keep in view — a configured expected set — and a per-response comparison against it. That is exactly what DSI does.

DSI does not certify answer quality, safety, compliance, or truth. It measures coverage against a configured expected set and records reproducible omission evidence — a different property from the tools above, meant to sit alongside them.
